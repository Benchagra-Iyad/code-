# HTML & CSS practice

A small collection of front-end exercises built while learning page structure, responsive layouts, and Bootstrap.

## Contents

| Path | Description |
| --- | --- |
| [`menu.html`](menu.html) | Basic restaurant menu page with separate sections for chicken, beef, and sushi. |
| [`css/styles.css`](css/styles.css) | Initial page styling. |
| [`module2-solution/`](module2-solution/) | A restaurant-menu layout using Bootstrap 3 and custom CSS. |

## Run locally

These are static pages, so no build tools or server are required.

1. Clone or download this repository.
2. Open `menu.html` or `module2-solution/index.html` in a browser.

The Bootstrap-based example loads Bootstrap and jQuery from external CDNs, so those assets need an internet connection.
